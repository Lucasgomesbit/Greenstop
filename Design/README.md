# 🎨 Design & Identidade Visual — Greenstop

Esta pasta reúne todos os recursos gráficos, protótipos de interfaces, tokens de design e ativos visuais criados no Figma para o desenvolvimento do aplicativo **Greenstop**.

## 📁 Conteúdo da Pasta

* **[`telas/`](./telas):** Protótipos completos de todas as telas e fluxos de navegação do aplicativo em alta resolução.
* **[`icones/`](./icones):** Biblioteca de ícones e elementos gráficos padronizados para implementação no código.

## 🎨 Variáveis e Tokens de Design

Abaixo estão os valores exatos configurados na coleção de variáveis do Figma para manter a consistência visual no código:

### Paleta de Cores

| Token / Uso | Código HEX | Aplicação |
| :--- | :--- | :--- |
| **Botões principais** | `#22C55E` | Ações primárias e botões de destaque |
| **Ícones e destaques** | `#166534` | Ícones ativos e elementos de ênfase |
| **Fundos suaves** | `#DCFCE7` | Áreas de destaque leve e estados sutis |
| **Fundo principal** | `#FFFFFF` | Fundo padrão das telas |
| **Cartões e entradas** | `#F1F5F9` | Campos de formulário (*inputs*) e cards |
| **Textos principais** | `#0F172A` | Títulos e textos de leitura principal |
| **Textos secundários** | `#64748B` | Subtítulos, rótulos e *placeholders* |
| **Avaliações** | `#FACC15` | Estrelas de classificação e notas |

### Tipografia e Medidas

| Variável | Valor |
| :--- | :--- |
| **Fonte (`Corda`)** | `Roboto Mono` |
| **Número base (`Número`)** | `0` |
