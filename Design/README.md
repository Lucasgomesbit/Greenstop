# 🎨 Design & Identidade Visual — Greenstop

Esta pasta reúne todos os recursos gráficos, protótipos de interfaces e ativos visuais criados no Figma para o desenvolvimento do aplicativo **Greenstop**.

## 📁 Conteúdo da Pasta

* **[`telas/`](./telas):** Protótipos completos de todas as telas e fluxos de navegação do aplicativo em alta resolução.
* **[`icones/`](./icones):** Biblioteca de ícones e elementos gráficos padronizados para implementação no código.

## 🎯 Diretrizes Visuais
* **Paleta de Cores:** Predominância de tons de verde (remetendo à mobilidade sustentável) combinados com fundo claro e alto contraste para leitura rápida.
* **Tipografia e Espaçamento:** Interfaces limpas e objetivas, focadas na facilidade de uso durante o deslocamento diário dos estudantes.
